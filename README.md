## ✨ Features

- 📊 Fetches the top **200 coins** by market cap (USD) from the [CoinGecko API](https://www.coingecko.com/en/api) when the page loads.
- 🎨 Styled with Bootstrap and a custom stylesheet.
- ⚡ No build step, no dependencies - just open the page.

## 🚀 Getting Started

```bash
git clone https://github.com/Arashomranpour/Crypto.git
cd Crypto
```

Open `index.htm` in a browser, or serve the folder:

```bash
python -m http.server 8000     # http://localhost:8000/index.htm
```
